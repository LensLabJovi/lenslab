Sobre o projeto

Reimaginamos a experiência da câmera

O LensLab é um projeto acadêmico desenvolvido para as disciplinas de Front-End Design e Web Development na FIAP. Combinamos design moderno com interações dinâmicas para entregar uma aplicação web completa, construída do zero com HTML, CSS e JavaScript puro.
